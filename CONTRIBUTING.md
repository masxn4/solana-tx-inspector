# Contributing

Contributions are welcome.

## Local development

1. Fork or clone the repository.
2. Install dependencies with `npm install`.
3. Run `npm run check` and `npm test`.
4. Keep changes focused and add tests for new analysis behavior.

## Pull requests

Describe the debugging problem your change solves, include test coverage where practical, and avoid unrelated formatting changes.

## Ideas

Useful areas include instruction decoding, address lookup tables, token transfer summaries, program labels, fixture-based tests, and RPC error handling.
